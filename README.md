# Usage

```
$ ./Roco
使用方法：
使用方法：
解密: Roco [--index <index路径>] [--download <下载目录>] <文件路径>
加密: Roco [--index <index路径>] [--download <下载目录>] <文件路径> <要 patch 的资源文件>
更新资源 index: Roco [--index <index路径>] update-index
下载全部资源:   Roco [--index <index路径>] [--download <下载目录>] download-all

选项：
  --index <路径>    指定 index.json 的路径（默认: index.json）
  --download <目录> 指定下载目录（默认: downloads）
```
